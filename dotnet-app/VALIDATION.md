## Default shared connection update

The backend and desktop now share the encrypted connection profile, with explicit deployment overrides (`DATABASE_URL_POOLED` before `DATABASE_URL`). The pooled Neon endpoint is the saved default. The workflow test runs the admin and print clients through separate backend instances connected to the same isolated database, covering shared visibility and immediate session revocation across instances.

The two requested portal logins were provisioned atomically using the final native executable against Neon. Each has a different generated password, stored in Neon as a salted hash and delivered separately to the user. Credentials are not included in the package or documentation. Provisioning refuses to replace existing logins; integration tests cover both username aliases and their distinct permissions.
